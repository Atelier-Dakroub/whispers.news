What you get

A finished site, not a starting point

Everything a headline site needs and nothing it doesn't. The layout, the typography and the admin are already decided, so the work left to you is picking stories.

Posting

An admin built for links

Paste a URL, write the headline, publish. Tracking parameters are stripped and a link already posted is refused, so the same story never runs twice. Mark one as breaking and it goes to the top in its own color — and stops being breaking on its own, so nothing is still flashing red three days later.

Look

Every color and font is yours

Eight colors, two font stacks, light and dark, reading density, day headings on or off — all from the admin, with a live preview. It measures what you pick with APCA and tells you when a pair is hard to read, then saves it anyway if that is what you want.

Hosting

Anywhere JavaScript runs

Node, Bun, Deno or Cloudflare Workers — a VPS, a Raspberry Pi, or the edge, from the same code. A SQLite file by default, with Turso, Postgres and Cloudflare D1 if you would rather. Moving hosts is a copy and a deploy.

Ownership

The whole source, forever

You get the repository, not an account. Read it, change it, fork it. Nothing phones home, nothing expires, and there is no key to enter.

Getting started

Three steps to a live front page

01

Clone and install

Pull the repository, run npm install and npm run db:migrate. Node, Bun, Deno and Cloudflare Workers all run the same code.

02

Open it and claim the site

The first visitor to an unclaimed site gets a setup page and makes the first account. No seed script, no hash to generate on a command line, nothing to edit before it will let you in.

03

Deploy and start posting

Push to your host. The front page is cached and served as bytes, so it holds up on the day a story takes off — which is the only day it matters.

Questions

Before you buy

What counts as commercial?

Money changing hands because of the site. Display ads, sponsored posts, affiliate links, a paid newsletter, or a site owned by a company. A personal or hobby site with none of that is free — including one that gets a lot of traffic.

How many sites can I run?

As many as you want, on either license. There is no key to enter and nothing counting your installs. One purchase covers every site you run, including sites you build for clients.

Can I change the code?

Yes, that is the point. Rewrite the templates, swap the storage layer, bolt on a newsletter. The one thing you cannot do is resell Whispers itself as your own product.

What do I need to run it?

Node, Bun or Deno and somewhere to put it — or a Cloudflare account and nothing else. Data lives in a single SQLite file by default, so there is no database server to set up or pay for. Turso, Postgres and Cloudflare D1 are supported from the same code if you would rather.

Can more than one person post?

Yes. Add people from the admin and each gets their own passphrase, shown once. Removing someone locks them out immediately and does not disturb anybody else — which is the reason the passphrases are not shared.

What do I actually get when I pay?

The right to run it commercially, and an invoice that proves it. The code is the same code the free tier clones — there is no key to enter, no account to activate and nothing counting your installs, so there is also nothing that can stop working. Payment goes through Polar, which is the merchant of record, so sales tax and VAT are handled and the receipt comes from them.

Do I have to credit Whispers?

A “Powered by Whispers” line renders in the footer by default, and a setting turns it off. The personal license asks you to keep it; the commercial one does not require it. Nothing checks — there is no key to enter and nothing counting installs, so it is your call to make honestly.

Is there a feed?

Yes, at /feed.xml, built from the same headlines and updated as you post. Nothing to configure.

Will I have to buy this again?

Not for what you bought. Your license keeps working forever and every 1.x update is included. There may never be a major version at all — if one comes, it is a separate purchase, it happens no more often than once every 18 months, and only when something genuinely breaks compatibility. Buy within 60 days of a major's release and the upgrade is free.

Why not just use WordPress?

You can, and there are good themes for it. Whispers is for people who would rather not run WordPress at all: no plugin updates, no security surface you did not ask for, and a front page that stays fast without a caching stack in front of it.
